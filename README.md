# 🎮 GameShop - Онлайн-магазин видеоигр

Django Python SQLite Bootstrap

**GameShop** - это полнофункциональное веб-приложение онлайн-магазина видеоигр, построенное на Django. Система предоставляет пользователям возможность покупать игры за реальные деньги или заработанные в викторине очки, участвовать в игровой рулетке для получения призов, а также проходить викторины для накопления игровой валюты.

## 🚀 Возможности

### 🛒 **Управление магазином**

* Каталог видеоигр с детальной информацией
* Категоризация и фильтрация игр
* Система распродаж и скидок
* Отображение новинок и рекомендуемых игр
* Интеграция с Steam API для получения информации об играх

### 💳 **Система покупок**

* Покупка игр за реальные деньги (заглушка платежей)
* Покупка игр за очки, заработанные в викторине
* Сохранение банковских карт для быстрых платежей
* Управление личной библиотекой игр
* Защита от повторных покупок

### 🎯 **Викторина**

* Случайные вопросы с вариантами ответов
* Начисление очков за правильные ответы
* Отслеживание серий правильных ответов
* Русскоязычные вопросы
* Автоматическое получение вопросов через API

### 🎰 **Игровая рулетка**

* Игровое колесо с призами
* Ограничение попыток (5 в день)
* Автоматическое добавление выигранных игр в библиотеку
* Различные рулетки с разными призами

### 👤 **Управление пользователями**

* Регистрация и авторизация
* Управление балансом и очками
* Пополнение баланса
* Личная библиотека игр
* История покупок

### 🎨 **Современный интерфейс**

* Адаптивный дизайн с Bootstrap 5.3.3
* Интуитивная навигация
* Красивые карточки игр
* Отображение статусов и скидок
* Мобильная версия

## 🛠️ Технологический стек

### Backend (Django)

* **Framework:** Django 5.2.7
* **Database:** SQLite
* **Authentication:** Django Auth System
* **API Integration:** Steam API (частично)
* **HTTP Client:** requests, httpx
* **Translation:** googletrans

### Frontend

* **Framework:** Django Templates

## 🚀 Быстрый старт

### Требования

* Python 3.8+
* pip
* Git

### 1. Клонирование репозитория

```bash
git clone https://github.com/StaKuzyao/zhtsrpo.git
cd zhtsrpo
```

### 2. Создание виртуального окружения

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/Mac
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Применение миграций

```bash
python manage.py migrate
```

### 5. Создание суперпользователя (опционально)

```bash
python manage.py createsuperuser
```

### 6. Заполнение базы данных (опционально)

```bash
# Заполнение категорий
python manage.py seed_categories

# Заполнение игр
python manage.py seed_games

# Заполнение рулетки
python manage.py seed_roulette

# Заполнение вопросов викторины
python manage.py seed_ru_questions
```

### 7. Запуск сервера разработки

```bash
python manage.py runserver
```

Приложение будет доступно по адресу `http://127.0.0.1:8000/`

## 🔧 Конфигурация

### Настройки базы данных

По умолчанию используется SQLite. Для изменения настроек отредактируйте `gameshop/settings.py`:

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',
    }
}
```

### Настройки безопасности

⚠️ **Важно:** Перед развертыванием в продакшене:

1. Измените `SECRET_KEY` в `settings.py`
2. Установите `DEBUG = False`
3. Настройте `ALLOWED_HOSTS`
4. Используйте PostgreSQL вместо SQLite
5. Настройте HTTPS

## 🎯 Основные функции

### Покупка игр

1. Просмотр каталога игр
2. Выбор игры и просмотр деталей
3. Покупка за деньги или очки
4. Автоматическое добавление в библиотеку

### Викторина

1. Открытие страницы викторины
2. Ответ на случайный вопрос
3. Получение очков за правильный ответ
4. Отслеживание серии правильных ответов

### Рулетка

1. Выбор рулетки
2. Вращение колеса (стоимость списывается с баланса)
3. Получение приза (игра автоматически добавляется в библиотеку)
4. Ограничение: 5 попыток в день
