# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
## Проект "GameShop" - Онлайн-магазин видеоигр

---

## 1. Введение

**Название продукта:** GameShop

**Описание продукта:** GameShop - это веб-приложение онлайн-магазина видеоигр, построенное на Django. Система предоставляет пользователям возможность покупать игры за реальные деньги или заработанные в викторине очки, участвовать в игровой рулетке для получения призов, а также проходить викторины для накопления игровой валюты.

**Границы проекта:**
- ✅ Покупка игр за деньги и очки
- ✅ Система викторин для заработка очков
- ✅ Игровая рулетка с призами
- ✅ Управление пользовательскими аккаунтами и балансами
- ✅ Система категорий и фильтрации игр
- ✅ Административная панель для управления контентом
- ❌ Реальная обработка платежей (используются заглушки)
- ❌ Система доставки игр (цифровой контент)
- ❌ Многоязычность (только русский язык)
- ❌ Мобильное приложение

---

## 2. Требования пользователя

### 2.1 Программные интерфейсы

**Внешние системы и библиотеки:**
- **Django 5.2.7** - основной веб-фреймворк
- **SQLite** - база данных для хранения данных
- **Bootstrap 5.3.3** - CSS-фреймворк для пользовательского интерфейса
- **googletrans** - библиотека для перевода вопросов викторины
- **httpx/httpcore** - HTTP-клиент для внешних запросов
- **requests** - библиотека для HTTP-запросов
- **certifi** - сертификаты для безопасных соединений

**Интеграции:**
- **Steam API** (частично) - для получения информации об играх через Steam ID
- **Внешние API викторин** - для получения вопросов через команды управления

### 2.2 Интерфейс пользователя

**Текстовое описание интерфейса:**

**Главная страница:**
- Навигационная панель с логотипом GameShop
- Меню: Главная, Магазин, Рулетка, Викторина
- Отображение баланса пользователя и очков (для авторизованных)
- Кнопки входа/регистрации (для неавторизованных)
- Секции: Горячие акции, Распродажи, Новинки, Категории игр

**Страница магазина:**
- Сетка игр с изображениями, названиями, ценами
- Фильтры по категориям и статусу (распродажа, новинка, рекомендуемые)
- Карточки игр с информацией о скидках и очковой стоимости

**Страница игры:**
- Подробная информация об игре
- Кнопки покупки за деньги или очки
- Отображение статуса владения игрой

**Страница рулетки:**
- Игровое колесо с призами
- Отображение оставшихся попыток
- Кнопка вращения рулетки
- История выигрышей

**Страница викторины:**
- Вопрос с вариантами ответов
- Отображение текущей серии правильных ответов
- Система начисления очков за правильные ответы

**Страница пополнения баланса:**
- Форма ввода суммы пополнения
- Поля для данных банковской карты
- Возможность сохранения карты для будущих платежей

### 2.3 Характеристики пользователей

**Основные группы пользователей:**

1. **Обычные покупатели игр**
   - Возраст: 16-35 лет
   - Образование: среднее/высшее
   - Опыт: базовые навыки работы с веб-браузерами
   - Техническая грамотность: средняя
   - Цель: покупка видеоигр для развлечения

2. **Геймеры-энтузиасты**
   - Возраст: 18-40 лет
   - Образование: высшее техническое
   - Опыт: активные пользователи игровых платформ
   - Техническая грамотность: высокая
   - Цель: поиск новых игр, участие в акциях

3. **Казуальные игроки**
   - Возраст: 25-50 лет
   - Образование: различное
   - Опыт: ограниченный опыт покупок онлайн
   - Техническая грамотность: низкая-средняя
   - Цель: простые покупки игр без сложных функций

### 2.4 Предположения и зависимости

**Технические зависимости:**
- Стабильное интернет-соединение для работы с внешними API
- Современные веб-браузеры с поддержкой JavaScript
- Сервер с поддержкой Python 3.8+ и Django

**Бизнес-зависимости:**
- Наличие банковских карт у пользователей для пополнения баланса
- Доступность внешних API для получения вопросов викторины
- Стабильность Steam API для получения информации об играх

**Ограничения:**
- Система не обрабатывает реальные платежи (заглушки)
- Ограниченное количество попыток в рулетке (5 в день)
- Только русскоязычные вопросы в викторине

## 3. Системные требования

### 3.1 Функциональные требования

**FR-001: Управление пользователями**
- FR-001.1: Система должна предоставлять возможность регистрации новых пользователей

- FR-001.3: Система должна предоставлять возможность выхода из аккаунта
- FR-001.4: Система должна хранить баланс пользователя в рублях
- FR-001.5: Система должна хранить количество очков пользователя

**FR-002: Управление играми**
- FR-002.1: Система должна отображать каталог всех доступных игр
- FR-002.2: Система должна предоставлять детальную информацию о каждой игре
- FR-002.3: Система должна поддерживать категоризацию игр
- FR-002.4: Система должна поддерживать фильтрацию игр по категориям
- FR-002.5: Система должна поддерживать фильтрацию игр по статусу (распродажа, новинка, рекомендуемые)
- FR-002.6: Система должна отображать изображения игр
- FR-002.7: Система должна поддерживать скидки и акции

**FR-003: Система покупок**
- FR-003.1: Система должна позволять покупать игры за реальные деньги
- FR-003.2: Система должна позволять покупать игры за очки
- FR-003.3: Система должна предотвращать повторную покупку уже купленной игры
- FR-003.4: Система должна сохранять информацию о способе оплаты
- FR-003.5: Система должна отображать статус владения игрой

**FR-004: Система пополнения баланса**
- FR-004.1: Система должна предоставлять форму пополнения баланса
- FR-004.2: Система должна поддерживать ввод данных банковской карты
- FR-004.3: Система должна позволять сохранять карты для будущих платежей
- FR-004.4: Система должна использовать сохраненные карты для пополнения

**FR-005: Система викторины**
- FR-005.1: Система должна отображать случайные вопросы викторины
- FR-005.2: Система должна предоставлять варианты ответов
- FR-005.3: Система должна начислять очки за правильные ответы
- FR-005.4: Система должна отслеживать серии правильных ответов
- FR-005.5: Система должна поддерживать только русскоязычные вопросы

**FR-006: Система рулетки**
- FR-006.1: Система должна предоставлять игровую рулетку
- FR-006.2: Система должна ограничивать количество попыток в день (5 попыток)
- FR-006.3: Система должна списывать стоимость вращения с баланса
- FR-006.4: Система должна выдавать призы (игры) при вращении
- FR-006.5: Система должна автоматически добавлять выигранные игры в библиотеку

**FR-007: Административная панель**
- FR-007.1: Система должна предоставлять интерфейс для управления играми
- FR-007.2: Система должна предоставлять интерфейс для управления категориями
- FR-007.3: Система должна предоставлять интерфейс для управления пользователями
- FR-007.4: Система должна предоставлять интерфейс для управления рулеткой
